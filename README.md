# Thi Hong Le — Portfolio

A clean, responsive portfolio website for internship applications.

## Files
- `index.html` — main page
- `style.css` — styling and responsive layout
- `script.js` — small scroll interaction

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Create a GitHub repository, e.g. `thi-hong-le-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Save. GitHub will provide your public portfolio URL.


## Project links
Replace each `PASTE_GOOGLE_DRIVE_LINK_HERE` in `index.html` with the
corresponding Google Drive folder link for that project.
